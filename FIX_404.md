# 🔴 404 - Solução Rápida

Se você está vendo **404 (Not Found)** no Discloud, o problema é que o `dist/` não foi servido.

## ⚡ Causas Prováveis (em ordem de probabilidade)

1. **Variáveis de Ambiente NÃO foram configuradas** ← **MAIS PROVÁVEL**
2. `PRE_INSTALL=npm run build` não executou ou falhou
3. Servidor não conseguiu fazer fallback build

## ✅ Solução em 3 passos

### Passo 1: Verificar Variáveis de Ambiente

No **Painel Discloud** → **Variáveis de Ambiente**:

✅ Verifique se TODAS essas variáveis estão lá:

- [ ] `NODE_ENV` = `production`
- [ ] `SESSION_SECRET` = (algo seguro, não pode ser placeholder)
- [ ] `STEAM_API_KEY` = (sua chave, não pode ser placeholder)
- [ ] `STEAM_ADMINS` = `76561198419559590`
- [ ] `FRONTEND_URL` = `https://brasilsimracing.discloud.app`
- [ ] `STEAM_RETURN_URL` = `https://brasilsimracing.discloud.app/auth/steam/return`
- [ ] `STEAM_REALM` = `https://brasilsimracing.discloud.app`
- [ ] `TRUST_PROXY` = `1`

**Se faltar alguma**, adicione e salve.

### Passo 2: Reiniciar Aplicação

- Clique em **"Reiniciar"** ou **"Redeploy"**
- Aguarde 30-60 segundos

### Passo 3: Acompanhar Logs

Abra a **aba de Logs** e procure por:

✅ **Se vir estas linhas, está OK:**
```
✅ BSR Server Starting
📌 Environment: production
🔐 Steam configured: Yes
   Return URL: https://brasilsimracing.discloud.app/auth/steam/return
✅ Frontend build completed successfully
```

OU (fallback):
```
✅ Fallback build completed successfully to temporary directory
```

❌ **Se vir isto, as env vars NÃO foram configuradas:**
```
Return URL: http://localhost:8080/auth/steam/return
Session cookie config -> secure: false
🔧 Dist directory not found
```

## 🐛 Se ainda der 404 após isso

Execute este comando **localmente** na pasta do projeto para diagnosticar:

```bash
./diagnose.sh
```

Depois compartilhe:
1. Output do `diagnose.sh`
2. Screenshot dos **Logs do Discloud**
3. Screenshot das **Variáveis de Ambiente do Discloud**
